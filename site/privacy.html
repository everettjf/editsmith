Privacy

Privacy Policy

EditSmith keeps actions and settings on your Mac and makes model use explicit.

No developer-operated service

EditSmith does not send source text, actions, test fixtures, settings, or usage data to a server operated by the developer.

Local execution

JavaScript actions run locally through JavaScriptCore. Apple On-Device model actions run through the Foundation Models framework. The Source Editor Extension receives only the text and selections supplied by XcodeKit when you invoke an action.

Optional model providers

A user-invoked Private Cloud Compute or Ollama action may send the selected text, or the full buffer when there is no selection, to that provider. EditSmith never chooses a remote provider implicitly.

Local storage

Actions, prompts, provider configuration, test fixtures, settings, and the most recent undo snapshot are stored locally in the app's shared container.

Network permission

Ollama requires a build with outgoing-network permission. Builds without that entitlement cannot connect to Ollama. Private Cloud Compute availability and processing are governed by Apple's platform service.

Questions may be sent to xnuapp@gmail.com.
